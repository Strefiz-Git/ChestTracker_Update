# Changelog

## 3.0.0

First release of this independently maintained 26.3 line, forked from the 26.3 unofficial port.

[change] Re-branded the project: mod id, name, contact links, POM metadata and publishing targets are now this
repository's own. The original author (JackFred) and the 26.3 port author (ponuing) are credited as contributors.

[update] Where Is It is now resolved from the Modrinth maven instead of GitHub Packages, and JackFredLib is taken from
the published Where Is It jar. Building no longer requires a `GITHUB_TOKEN` or any private maven credentials.

[update] Litematica, MaLiLib and JackFredLib are compiled against jars vendored in `libs/`, since there is no public
maven for 26.3.

[fix] The WTHIT integration is now compiled out through the `wthit_version` property rather than a hardcoded source set
exclusion, and its config toggle is hidden while the integration is not compiled in. WTHIT has no 26.3 build yet.

[fix] Removed the unused `dotenv` Gradle plugin and unused maven repositories (Nucleoid, Shedaniel).

[fix] Gradle `properties` access inside the POM block no longer resolves to the wrong receiver.

[docs] Replaced the README with build instructions, dependency notes and a known-limitations section.

Bundled:
  - Where Is It: 2.7.5.2+26.3
  - Searchables: 26.3:1.0.2
